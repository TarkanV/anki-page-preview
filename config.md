# Page Preview Configuration

- **openDelay**: Milliseconds to pause on a link before opening (default: 120). Prevents vertical list skimming from opening popups.
- **closeDelay**: Milliseconds grace period before closing popups (default: 150).
- **maxWidth**: Maximum width of the popup (e.g. "65vw", "600px", or "min(650px, 60vw)").
- **maxHeight**: Maximum height of the popup (e.g. "52vh" or "400px").
- **minWidth**: Minimum width of the popup (default: "320px").
- **fontSize**: Text size inside the popup (default: "14px").
- **lineHeight**: Line spacing inside the popup (default: "1.5").
- **gap**: Pixel gap between the trigger link and the popup (default: 2).
- **viewportMargin**: Minimum padding from the edges of the window (default: 24).
